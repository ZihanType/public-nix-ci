# Snipaste 安装包镜像

保存 Snipaste 官方的 macOS 和 Linux 安装包，使消费方能够获取镜像文件及其发布索引。

## 领域语言

**官方安装包**：
Snipaste 官方面向 macOS 发布的 Universal DMG，或面向 Linux x86_64 发布的 AppImage。
_避免_：镜像安装包

**官网最新版本**：
Snipaste 官方当前下载入口为某一平台提供的版本；macOS 与 Linux 各自确定，不要求版本号相同。
_避免_：所有平台共享的最新版本号

**镜像修订**：
某个目标系统及架构的官方安装包的一份固定内容；同一官方版本可以对应多个镜像修订，已发布的修订及其下载地址保持不变。
_避免_：把官方版本号当作唯一内容标识

**发布索引**：
汇集各目标最新镜像修订的清单；每个目标具有独立的版本号、下载地址和内容校验值。
_避免_：安装包本身
