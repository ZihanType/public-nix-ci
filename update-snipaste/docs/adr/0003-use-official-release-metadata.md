# 使用官网发布信息识别版本并核对安装包

用户要求跟踪 Snipaste 官网当前提供的 macOS 和 Linux 安装包。官网通过 versions 接口分别提供 mac_version、linux_version，当前下载入口重定向到带版本号的文件，并提供 SHA-1 清单。因此，以官网发布信息识别各平台最新版本，每次完整下载后核对最终文件名中的版本及官方 SHA-1，再计算用于镜像修订和发布索引的 SHA-256。

延续微信镜像对同版本换包的检测，但版本识别依赖官网元数据，不通过解包提取内部版本；这样两个平台使用同一套元数据校验流程，无须跨平台解包或执行官方程序。缺少必要元数据、版本或 SHA-1 不一致时任务失败，保留旧索引。
