# 微信安装包镜像

保存微信 Linux 官方安装包的历史内容，使消费方能够固定所需的版本和内容。

## 领域语言

**官方安装包**：
微信官方为 x86_64 或 ARM64 提供的 Linux AppImage 安装包；相同版本号的安装包内容也可能改变。
_避免_：镜像安装包

**镜像修订**：
某一架构的官方安装包的一份固定内容。同一官方版本可以对应多个镜像修订，已发布的修订及其下载地址保持不变。
_避免_：把官方版本号当作唯一内容标识

**发布索引**：
汇集各架构最新镜像修订的记录；每个架构拥有独立的版本号、下载地址和内容校验值，架构之间无需具有相同版本号。
_避免_：所有架构共享的最新版本号
