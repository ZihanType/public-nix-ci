# 直接打包正式 Release 的源码归档

当上游没有提供可用的扩展 ZIP 附件时，扩展目录可以显式选择最新正式 Release 对应的源码归档，从归档中选择已存在的扩展文件并规范化、重签为 CRX，以继续使用同一套可复现产物和不可变版本校验。源码归档打包不执行上游构建命令，也不负责生成缺失的运行时文件；需要编译才能获得扩展文件的项目仍应使用上游已构建的发布附件，避免把本组件扩大成通用构建系统。

文件选择由扩展目录中的通用 `include` 清单声明，使用仓库相对的精确文件或目录路径，不在代码中维护 ClearURLs 专用规则；清单必须非空且每项都须选中文件，以便上游目录变化时显式失败，而非继续发布缺文件的扩展。

此决策将 ADR-0007 的获取信任范围从发布附件扩展到同一正式 Release 关联的源码归档，并保留 ADR-0002 的产物解析边界。
